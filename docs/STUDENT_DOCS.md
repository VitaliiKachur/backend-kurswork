# STUDENT_DOCS

# Розробка вебзастосунку інтернет-магазину електротоварів "ТехОк"

## Вступ

Сучасна електронна комерція є одним із ключових напрямів розвитку торгівлі, оскільки покупці очікують швидкого доступу до каталогу товарів, актуальної інформації про наявність, зручного кошика та можливості оформити замовлення без відвідування фізичного магазину. Для магазинів техніки та електротоварів вебзастосунок дає змогу централізовано керувати асортиментом, замовленнями, клієнтами та залишками товарів.

Темою роботи є розробка вебзастосунку інтернет-магазину електротоварів "ТехОк" на базі курсового проєкту з вебпрограмування. Система реалізована як PHP MVC-застосунок з використанням MySQL для збереження даних, HTML/CSS/Bootstrap для побудови інтерфейсу та JavaScript для інтерактивних дій з кошиком і перевіркою даних.

**Мета роботи** - розробити та описати вебзастосунок інтернет-магазину, який забезпечує перегляд каталогу товарів, реєстрацію користувачів, роботу з кошиком, оформлення замовлень і адміністрування основних даних магазину.

Для досягнення мети необхідно виконати такі **завдання**:

- проаналізувати призначення та основні бізнес-процеси інтернет-магазину;
- визначити об'єкт, предмет і функціональні можливості системи;
- описати технологічний стек, використаний для розробки;
- реалізувати структуру застосунку за MVC-підходом;
- забезпечити роботу каталогу, кошика, профілю користувача та замовлень;
- підготувати документацію, яка може бути використана для подальшого розвитку або захисту проєкту.

**Об'єкт дослідження** - процес онлайн-продажу електротоварів через вебзастосунок.

**Предмет дослідження** - програмні засоби, архітектурні підходи та технології створення інтернет-магазину з каталогом товарів, кошиком, замовленнями та адміністративною панеллю.

**Актуальність роботи** полягає в тому, що онлайн-магазини дають змогу автоматизувати продажі, зменшити ручну роботу персоналу, покращити доступність товарів для покупців і забезпечити швидке оновлення інформації про асортимент. Для навчального проєкту така система також є актуальною, оскільки поєднує типові задачі веброзробки: маршрутизацію, роботу з базою даних, сесії, форми, валідацію, шаблони, авторизацію та інтерактивні запити.

**Практичне значення** роботи полягає в тому, що створений застосунок може бути використаний як основа для невеликого інтернет-магазину або як навчальний приклад побудови PHP MVC-проєкту. Система демонструє повний цикл взаємодії покупця з магазином: перегляд товарів, додавання до кошика, оформлення замовлення та перегляд історії покупок. Адміністративна частина дозволяє керувати товарами, категоріями, клієнтами та замовленнями.

## Розділ 1. Опис технологічного стеку

Для реалізації вебзастосунку інтернет-магазину "ТехОк" використано технологічний стек, орієнтований на класичну серверну веброзробку. Основою системи є мова програмування PHP, яка відповідає за обробку HTTP-запитів, роботу з моделями, маршрутизацію, формування HTML-сторінок і взаємодію з базою даних. PHP є придатним для цього проєкту, оскільки добре підтримується локальними середовищами на кшталт WAMP, має просту інтеграцію з MySQL і дозволяє швидко створювати динамічні вебсторінки.

Архітектура застосунку побудована за підходом MVC. У папці `controllers` розміщені контролери, які приймають запити користувача та визначають подальші дії системи. Наприклад, `ProductController` відповідає за перегляд товарів, `CartController` - за кошик і оформлення замовлення, `ProfileController` - за реєстрацію, авторизацію та профіль клієнта. У папці `models` зосереджені класи для роботи з даними: `Products`, `Categories`, `Customers`, `Cart`, `Order`, `OrderItem`. Представлення розміщені в папці `views` і відповідають за відображення сторінок користувачу. Такий поділ робить код зрозумілішим, полегшує підтримку та дозволяє окремо змінювати логіку, дані або інтерфейс.

Для збереження інформації використовується MySQL. У базі даних зберігаються товари, категорії, клієнти, кошики, замовлення та позиції замовлень. Робота з БД виконується через клас `DB` у папці `core`, а складніші вибірки реалізовані в моделях за допомогою SQL-запитів. Наприклад, список товарів формується з урахуванням категорії, пошуку, фільтрів ціни та сортування. Для створення замовлення використовується транзакція: система створює запис замовлення, додає позиції, зменшує залишки товарів і лише після успішного завершення зберігає зміни.

Користувацький інтерфейс побудовано за допомогою HTML, CSS і Bootstrap. HTML використовується для структури сторінок, CSS - для стилізації, а Bootstrap - для готових компонентів, адаптивної сітки, кнопок, форм і навігації. У проєкті передбачені сторінки головного екрана, категорій, товарів, профілю, кошика, оформлення замовлення та адміністративної панелі. Завдяки адаптивним можливостям Bootstrap інтерфейс може коректно відображатися на різних розмірах екрана.

JavaScript використовується для інтерактивних дій без повного перезавантаження сторінки. Зокрема, він виконує запити до внутрішніх JSON-ендпоінтів, таких як додавання товару до кошика, отримання кількості товарів у кошику та перевірка email під час реєстрації. Для обміну даними використовується формат JSON, що дозволяє клієнтській частині швидко обробляти відповіді сервера та оновлювати окремі елементи інтерфейсу.

Маршрутизація реалізована через файл `config/routes.php`, де кожному URL відповідає певний контролер і дія. Такий підхід дозволяє централізовано керувати адресами сторінок і endpoint-ів. Додатково в проєкті використовується файл `.htaccess`, який допомагає спрямовувати запити до єдиної точки входу `index.php`. Це відповідає типовій структурі MVC-застосунків і спрощує навігацію між сторінками.

Локальне середовище розробки базується на WAMP, який поєднує вебсервер Apache, PHP та MySQL. Такий набір зручний для навчальної розробки, оскільки дозволяє запускати застосунок на локальному комп'ютері без додаткового розгортання на хостингу. Для зберігання вихідного коду використовується Git, а GitHub може застосовуватися для створення pull request-ів, перегляду змін і збереження документації проєкту.

Отже, обраний технологічний стек є достатнім для реалізації навчального інтернет-магазину. Він охоплює серверну логіку, базу даних, інтерфейс користувача, інтерактивні запити та контроль версій. Використання PHP MVC, MySQL, Bootstrap і JavaScript дозволяє створити повноцінний вебзастосунок із типовими функціями електронної комерції.
